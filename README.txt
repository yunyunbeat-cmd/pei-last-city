ぺいの終末散歩 — ステージ1 更新版

【起動方法】
ZIPを右クリックして「すべて展開」し、pei-last-city内のindex.htmlをEdgeやChromeで開いてください。
インストールやインターネット接続は不要です。
同梱ファイルとaudioフォルダーの位置関係は変えないでください。

【今回の変更】
・5種類のパワーアップごとに専用MP3効果音を設定可能。audio/README.txtの対応名、またはゲーム内「音声設定」から指定できます。
・ボスのレーザーは1回50ダメージ。HP満タン100から2回被弾で倒れます。
・ゴールデンボールで10体倒すと破損して初期装備へ戻ります。草・NINJAの撃破は消耗しません。
・ボス増援は画面外から約2.8秒間隔で登場（同時最大5体）。
・制限時間120秒。ミスしても時間はリセットされません。一時停止中は止まります。
・時間切れで世界が爆発し、残機にかかわらずゲームオーバー。
・クリア時の残り時間は切り捨て秒数×10点。敵1体100点なので、10秒短縮が敵1体分です。
・クリア画面の「結果をPNGで保存」でスコア画像をダウンロードできます。
・ゴールデンボールの攻撃力を80に強化。歩行敵を一撃で撃破できます。
・NINJA専用BGM（audio/ninja.mp3）と金色の点滅を追加。
・ボス戦で飛行敵が少数出現します（同時に最大2体）。
・クリアメッセージを「クールだぜ。」に変更。
・ゴールデンボールは攻撃後に重力方向へ垂れ、移動時に少し揺れます。
・ボスのレーザーは予告開始時のプレイヤーの高さから上段／下段を選択します。
・ダッシュはCキーの切り替え方式です。
・4場面のBGM、8種類のSEをMP3で指定できる音声設定を追加。
・落下ミスは画面下へ落ち切ってから死亡SEを再生。
・高架の段差、昇降足場、横移動足場、乗り越える障害物を追加。
・コウモリ状の翼を持つ赤・青ノーツを追加。一撃で倒せますが、単発弾を発射します。
・ボス前の足場を地面から80〜87pxの高さに変更。
・ボスの後ろへ回ると、予告後に体当たりします。ジャンプして回避してください。

【音声】
右上「音声設定」でMP3を選択してください。選択音声はこのブラウザに保存されます。
ゲーム音は「SOUND OFF」をクリックしてオンにします。
MP3を直接配置する場合はaudio/README.txtの対応表を参照してください。
MP3素材そのものは同梱していません。

【操作】
← → または A D：移動
C：ダッシュON／OFF切り替え（方向キーと同時に押す必要はありません）
Space：ジャンプ（長押しで高く跳べます）
Z（長押し可）：攻撃
X：パワーアップ発動
Esc：一時停止・再開
R：最初からやり直し

【ルール】
敵が落とすキューブを拾い、欲しい段階でXを押します。
1：ツインダスモ / 2：スピア / 3：ゴールデンボール
4：NINJA（10秒無敵） / 5：草（画面内の雑魚を一掃）
発動でキューブを全消費。5個で満タン。
HPが0になるか穴に落ちると残機が減ります。
チェックポイントではHPが全回復。ボスを倒すとステージクリアです。
